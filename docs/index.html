Which agents are using your Mac?

See CPU and memory use for Claude Code, Codex and local MCP servers in one native menu bar app. Keep your Mac awake while they work.

macOS 15+ · Apple silicon & Intel

Technical beta. Gatekeeper may block this download. Installation details

Follow an agent from the menu bar.

Start with the three agents using the most memory. Open the full list to find the process you care about.

Compare local agents
Search by name or sort by CPU, memory or copies. Each root process counts as one copy, and its children contribute their usage.
Choose what stays awake
Keep the display on or prevent system sleep. A separate macOS agent keeps your choice active after the panel closes.
Keep activity on your Mac
Read local processes without an account or telemetry. Browser tabs and cloud-only agents are outside the monitor’s scope.

Install the technical beta.

macOS 15 or later. The compiled app runs without Xcode. The interface is in Brazilian Portuguese.

↓Download Beta 1
  1. Download and unzip the universal macOS app.
  2. Drag Manter Ativo.app into Applications.
  3. Open the app in Finder. Use “Abrir painel” in the menu bar to return to the dashboard.
